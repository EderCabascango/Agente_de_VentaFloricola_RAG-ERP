# Presentaciones y empaque de la flor

## Cómo se vende

La flor se vende por tallo, pero se arma, se empaca y se despacha así:

| Presentación | Equivale a |
|---|---|
| Bonche (ramo) | 25 tallos |
| Caja completa | 400 tallos (16 bonches de 25) |

- Todo pedido debe ser en bonches completos de 25 tallos.
- Los clientes pueden pedir en tallos, bonches o cajas: el sistema convierte a tallos para validar el stock y calcular el precio.
- Cada caja lleva una sola variedad y un solo largo, salvo acuerdo con el asesor para cajas mixtas.

## Largos

Las rosas se clasifican por largo de tallo: 50, 60 y 70 cm. A mayor largo, mayor precio. Si el cliente no dice el largo, se le pregunta.
